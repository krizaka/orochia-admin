# 🛡️ Orochia Admin Control Plane

The dedicated administrative and compliance control plane for the [Orochia](https://github.com/krizaka/orochia) ecosystem.

## Features

- **18 U.S.C. § 2257 Performer Compliance Vault**: Complete primary producer government identification archiving, age verification, and one-click federal audit dossier export.
- **DMCA & Moderation Triage**: Fast takedown processing with instant global Bunny.net Edge CDN purge (< 250ms invalidation).
- **Treasury & Administrator Monetization**:
  - **10% Protocol Rake** on tips, subscriptions, and pay-per-view unlocks.
  - **$49 Custodian Audit Fee** for 2257 federal performer vetting.
  - **Sanctuary Spotlight** paid hero placement auctions ($25/day).
  - **1.5% Fast-Lane Fee** for instant crypto (USDC/USDT) and SEPA payouts.
  - One-click batch payout approval and settlement.
- **Bunny.net Stream Telemetry**: Real-time PoP latency monitoring (114 PoPs), bandwidth tracking, storage zone distribution, and encoding status.
- **Creator & User Registry**: Role-based access control, account suspensions, and verification badges.

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server on port 3001
npm run dev -- -p 3001
```

Access the admin dashboard at `http://localhost:3001`.
